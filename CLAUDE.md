@AGENTS.md

Working on a FORGE task? Follow "Working on a FORGE task" in AGENTS.md. If
the FORGE tools are missing, ask your human to connect the `forge` server.
The repo doesn't include `.mcp.json` yet; until it does, add the connector
to Claude Code with
`claude mcp add --transport http forge https://forge-app-eta-mocha.vercel.app/mcp`,
then type `/mcp` to sign in (steps for other agents:
https://forge-app-eta-mocha.vercel.app/connect).
